# 个人短线量化 · short-term-quant

基于**舒九《个人关于投机的理解与做法》**方法论搭建的个人 A 股短线量化系统。
覆盖「盘后数据抓取 → 周期定位 → 核心识别 → 情绪/质地体检 → 形态扫描 → 前端复盘」完整链路，
云端定时任务驱动，手机端直接看盘。

> ⚠️ **免责声明**：本项目是个人研究/自律工具，不构成任何投资建议。
> 所有评分、分档、周期标签均为**离线统计口径**，不保证前瞻有效性。
> 短线交易风险极高，请独立判断、自负盈亏。

---

## 一、核心公式

```
收益 = 核心识别 × 周期定位 × 仓位管理 × 监管风控
```

四个因子不是加权求和而是**乘法**——任一为 0，整体归零。系统据此把「找票」和「择时」拆成两条独立管线，
再在体检页做交叉。

## 三、Lab 体检引擎（`quant/report/lab.py`）

系统里唯一做「质地 × 情绪」交叉的模块，五道闸门：

| 闸门 | 作用 | 口径 |
|---|---|---|
| **G1 排雷** | 一票否决 | ST / 质押 ≥50% / 商誉 ≥100% |
| **G2 质地 Q** | 打分 | 规模 40 + 盈利 35 + 估值 25 |
| **G3 情绪 E** | 打分 | 连板基准 + 核心 AB + 10 − verb 风控 |
| **G4 融合** | `Lab = Q×0.30 + E×0.70` | 权重经网格标定（E 主导单调更优） |
| **G5 排序** | 榜单 | verb（风险否决）优先级高于 Lab 分 |

**周期感知的 E**：`启动 +6 / 发酵 +3 / 高潮 板高×(−5) / 退潮 −16`，
周期 stage 取自当日快照 `cyc.stage`，缺失时按 6 日窗口懒算。

**已知边界（诚实标注）**：
- 权重 0.30/0.70 的复算样本仍偏少（目标 ≥30 交易日），当前阶段属于**弱校准**；
- 261 个交易日里「退潮」仅 3 天 → `−16` 属启发式，从未被充分校准，退潮期 Lab 分会整体塌陷，
  应理解为「整体不建议参与」而非「便宜机会」。

## 四、形态模块：双线粘合突破 MA7/MA21

| 项 | 口径 |
|---|---|
| 粘合 | `\|MA7 − MA21\| / MA21 ≤ 2.5%` 且**连续 ≥3 日** |
| 突破 | 当日**收盘上穿 MA21** 且 **MA7 上翘** |
| 量能 | `成交量 ≥ 前5日均量 × 1.5`（**确认旗标**，不参与突破判定） |
| 数据 | 腾讯日K，**前复权 qfq** |
| 候选池 | 当日涨停 ∪ 核心池（与 Lab 同池） |

> 扫描仅在「快照日 == 全局最新交易日」时执行，历史日不补算。

## 五、部署链路（CloudBase）

```bash
# 1) 引擎改动后，先同步到云函数副本，再从 cloud/ 目录部署
cp -rf quant/. cloud/functions/snapshot_py/quant/
cd cloud && tcb fn deploy snapshot_py      # 必须从 cloud/ 跑（cloudbaserc.json 所在）

# 2) 前端构建 + 静态托管
cd web && npm run build                    # 注意：不要 npm install
cd ../cloud && tcb hosting deploy ../web/dist quant -e <envId>
```

**踩坑记录**（血泪，别再犯）：
- `tcb fn deploy` 必须在 `cloud/` 目录执行，否则会打包整个 cwd 导致失败或静默跑旧码；
- 云函数内再调用长函数需显式 `callFunction({...}, {timeout: 60000})`，SDK 默认 15s 会静默超时；
- 云端 Python 3.7 需 `from __future__ import annotations`；时间戳用 `utcnow() + 8h`；
- 聚合文档**写回时必须合并保留旧字段**，否则每日结算会把 `replay` 等派生字段覆盖成 `null`。

## 六、数据边界（不虚构原则）

| 数据 | 可得性 |
|---|---|
| 腾讯 / 新浪 / 东财行情 | ✅ 可达 |
| 东财历史涨停池 | ⚠️ 仅约 15 个交易日 |
| 北向逐日持仓 / 净买卖 | ❌ 2024-08 起停发（仅剩前十大成交额，**无方向**，前端禁显净买/净卖） |
| 板块资金 / 人气 / 月线 | ❌ 需派生，不虚构数值 |

缺数据时输出**诚实占位**，绝不伪造链接或编造数值。
