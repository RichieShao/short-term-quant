1系统是什么

先纠正一个使用姿势：这套系统不预测明天涨跌，它做的是把盘面压缩成三件事——现在是什么周期、谁是核心、该配多少仓位。胜率来自"只在正确的阶段做正确的事"。

三层结构，一层决策

层回答什么落地页面
指标层情绪多热？谁分最高？离监管线多远？今日盘面 · 核心池 · 异动体检
状态层启动 / 发酵 / 高潮 / 震荡 / 退潮，现在在哪一站？今日盘面（CycleBar）
决策层周期 × 评分 → 动作 + 仓位上限 + 硬约束核心池（每只高标的动作）

数据怎么来的（决定你能信几分）

  • 交易日 16:05 云端定时任务自动算快照（16:40 幂等兜底重跑一遍），非交易日不更新——所以周末看到的是周五数据，这是正常的。
  • 温度/周期基于同花顺涨停池近一年（约 259 个交易日）回放校准的刻度，不是拍脑袋阈值。
  • 核心评分是代理口径：带动性用行业涨停家数近似、人气用连板高度位次近似，逻辑强度缺省 4/10 等你人工确认——这既是边界，也是你提高胜率的抓手（见第⑥节）。

2每日使用流程

收盘后 16:05 打开，5 分钟走完。盘中不建议看——这套是盘后定调、次日执行的系统。

1

今日盘面 → 确定周期阶段

看温度计读数和周期定位条，先问一个问题：现在是哪个阶段？这一步决定今天 80% 的动作。

2

核心池 → 看有没有 S/A 级标的

按评分排序，只关注 S（≥80）和 A（60–79）。B/C 级无论多好看，默认不碰——它们是 A 杀高发区。

3

逐票核对动作与硬约束

每只高标都带"动作 + 仓位上限 + 风险标注"。特别盯两类：禁接力（伪核心/中位一字）和异动高危（距严重异动线余量 <15% → 尾盘兑现）。

4

异动体检 → 查候选与持仓

输入代码看 3/10/30 日偏离值和 headroom（安全余量）。余量 <15% 的持仓，当天尾盘就该先手减，不等触发。

5

回测复盘 → 每周校准一次预期

看阶段分布和自评命中率，理解系统当下刻度是否贴合市场生态。命中率 5–7 个交易日才动 1 个单位，不是坏掉了。

6

次日盘中 → 只执行，不发明

按盘后定的清单执行。周期没变、评分没破线，就不管分时波动加戏——纪律本身就是优势。

3五个页面怎么用

🌡️

今日盘面

三指数 + 温度计表盘 + 6 日温度走势 + 周期定位 + 连板天梯 + 今日纪律。每天第一站。

🏆

核心池

高标评分卡（0–100 → S/A/B/C），展开看异动体检和风险扣分明细。决策主战场。

🔥

题材榜

当日涨停题材分布。看哪个板块在聚集跟随者——后排厚度是持续性的燃料。

⚖️

异动体检

任意代码 3/10/30 日偏离 + 严重异动余量 + 风险标签。监管风控的前哨。

📐

回测复盘

刻度校准样本窗口、转折点自评命中率、周期阶段分布。了解系统，不直接产生交易。

核心池评分卡读法

等级分数含义默认态度
S≥80总龙候选：带动性 + 持续性 + 无重大扣分唯一可重点参与
A60–79分支核心 / 待确认总龙看周期给仓位
B45–59地位不足或逻辑偏弱默认不做
C<45伪核心 / 一字断层 / 走弱禁接力

扣分项看得到：一字断层 −10、伪核心一字 −15、连续低开不创新高 −10、触发严重异动 −10……评分是显式可解释的，别只看总分。

三条硬约束（优先级高于矩阵）

  • 监管温度 ≤ −2（抓人 / 封账户级事件）→ 全线降半仓以下，高位核心只出不进。
  • 持仓进入严重异动高危区（余量 <15%）→ 尾盘兑现策略启动，不等到触发。
  • 中位股 / 补涨股永远禁止接力 —— 无论周期多好，这一条没有例外。

6怎么用，胜率更高

系统的胜率来自两个乘法：选对阶段 × 只做高评分。以下是六个经过回测与实战提炼的用法要点。

要点 1

周期错配，一票不做

全年的钱基本是发酵期赚的。震荡期能做但只高抛低吸核心；退潮期最强信号就是"没有信号"——空仓也是仓位。看阶段分布就知道：全年 259 日里退潮仅 2 天、震荡 126 天，大部分时间系统其实在告诉你"少动"。

要点 2

只买 S 级总龙，A 级看周期

评分 ≥80 且地位最高的那只才配重仓。A 级只在发酵期做分支逻辑；B/C 级无论故事多好听，16 分的"伪核心一字"就是大面源泉的实锤样本。宁可错过，不降档凑数。

要点 3

用好"需人工确认"清单

这是你比系统强的地方：逻辑强度缺省按 4/10 计（纯情绪），若你人工确认题材是业绩级/政策级，上调到 8 后 A/B 级候选可能直升 S/A——系统已经把预估分算好放在观察清单里。机器管分时以外的，你管题材真伪。

要点 4

异动余量当"卖点钟"用

headroom_10d <15% = 尾盘先手兑现，别赌"绕过去"。历史上绕异动成功固然次日高溢价，但集体抢跑触发监管就是板块级退潮。用体检页每天扫一遍持仓，把余量当倒计时。

要点 5

高潮日做减法，启动日做加法

高潮期的正确动作是持有不加 + 逐步兑现（加速=买盘枯竭前夜）；真正的机会在启动期的冰点反包——亏钱效应衰竭 + 溢价转正 + 首板批量出现后的第一个反包核心，往往是下一轮总龙。情绪周期里，底部敢试比顶部敢拿更值钱。

要点 6

卖点交给规则，不交给感觉

持仓跌破 60 分 → 减半（R2）；震荡期利好高开 → 直接兑现（R6）；总龙封板但跟风冲高回落 → 次日冲高出（R7）；上一核心 A 杀 → 下一核心大概率也 A 杀（R9）。卖点规则的价值不在单次对错，在于杜绝"多拿一天"的致命伤。

关于"自评命中率"的正确理解：复盘页的 68% / 100% / 87% 是同源重放的自洽性检查（规则在历史数据上是否自圆其说），不是未来胜率。顶点需其后 3 个交易日走完才确认，所以该数字每 5–7 个交易日才动 1 个单位——把它当系统体检指标，别当胜率承诺。

7一日决策清单（打印版）

每天收盘后照着勾，勾完就是明天的剧本。

  • 今日周期阶段是 ______；若是退潮/高潮后骤降 → 明日默认空仓或只留总龙，勾掉一切买入冲动。
  • 核心池有没有 S 级？有 → 名字 ______，按矩阵给仓位；没有 → 明日无新增买入计划。
  • 候选/持仓逐只过异动体检：余量 <15% 的 → 明日尾盘（或当日）先手兑现。
  • 有没有 禁接力 标签的中位/一字股在自选里诱惑我？→ 有，删自选，物理隔离。
  • "需人工确认"清单里，有没有我能拍板的业绩/政策级题材？→ 确认后重估等级再进决策。
  • 持仓有无跌破 60 分 / 连续低开不创新高？→ 触发 R2，减半，不商量。
  • 监管面：有无停牌 / 限制买入 / 问询级事件？→ 有则全线降档执行。

8能力边界（诚实声明）

  • 评分卡是代理口径：带动性 ← 行业涨停家数、人气 ← 连板高度位次、被动性 ← 炸板次数。分时级联动 / 龙虎榜数据不可得，标注为近似的部分需你复核。
  • 监管事件靠人工输入：小黑屋、封账户等无稳定数据源，系统默认 reg_temp=0，重大监管新闻要自己代入降档。
  • 周期判定是启发式：阈值虽经一年回放校准，但市场生态会漂移（刻度 2026-09 刚从旧饱和刻度换过来）。若发现连续多日"高潮"或长时间零"退潮"，应怀疑刻度过期，重新校准。
  • 本系统不构成投资建议：全部输出仅为个人研究用途的规则化复盘工具，仓位区间是纪律参考而非收益承诺。短线投机风险极高，盈亏自负。
